# Handy：全幅往復・高速化・動作と休憩のまとまり

2026-10-21、0.14.3/code21。0.14.2は本人が「さっきよりよい」と評価した一方、終盤は体感3倍ほど速く、上下端の全幅往復を多用し、動作も休憩もまとまりを持たせたいと依頼。小さな挿話も大きくし、上限の初期値を8.7cmへ変更する。これは本人の環境値で、メーカー仕様の物理上限ではない。

## 現行の調整

- フィニッシュの速度包絡は300〜400mm/秒、中間は120〜280を基に進行係数と音を反映し上限280、導入は48〜90。半往復ごとの92〜100%揺らぎ・弱化・3秒の復帰を維持する。機器が返す速度上限を常に優先し、本体設定は書き換えない。
- 全幅モードを2半往復単位で選び、下端→上端の組にする。抽選率は導入45%、中間65→90%、終盤96%。これは抽選率であり、実測の往復比率ではない。その他も80%はほぼ全幅、残りの位置変化は幅50〜72%を基準に、上側/下側などの中心を変える。
- 5次補間を、短い滑らかな加減速と長い速い中央部を持つ曲線へ変更。反転時の速度・加速度は0に接続するが待機しない。先読みは次の反転を越えず、その上下端を目標として送る。旧版の先読みが折り返しを飛び越えて幅と速度を縮める問題を修正する。
- 短い150〜350msの確率的な休みを廃止。導入16〜28秒/中間22〜38秒/終盤28〜48秒の動作ブロックの後、次の反転でそれぞれ3〜6秒/2.5〜5秒/2〜4秒休む。弱化中の追加休憩は入れない。
- 初期上限87mm。初回起動時に未設定または従来初期値85mmを87mmへ移行し、他の個別保存値は保持。一度だけ移行し、その後は編集値を維持する。機器の読取り上限との小さい方と両端1mm余白を引き続き使うため、87mmまで必ず動くという意味ではない。
- 接続・段階ボタン・時計・通常の位置差で止めない追従・専用停止・通信断時停止は[前版の基盤](handy-wave.md)を維持する。
