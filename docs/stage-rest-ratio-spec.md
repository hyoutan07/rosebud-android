# 0.8.0：段階別の休みの割合と連続動作

更新：2026-10-20。状態：本人が0.7.0を好感触としつつ中間/フィニッシュでも停止感が多いと申告し、段階ごとの停止量・波の谷の割合を変えられる設計を依頼。実装・74テスト・ビルド・Lint成功、同署名APK準備済み。以前の「中間を完全に保持」は今回の追加要望により更新する。

## 本人の意図と実装判断

- はじめ：間を多めにして弱い動作。中間：普通に動いている中へ短い休み。フィニッシュ：長い一連の動きが基本で、たまの休みが効く。強めも従来1秒より長く感じたい。
- 今回の0.7.0ログの1秒activeスナップショットは、はじめ52件中F0が17、中間36件中8、フィニッシュ13件中0。フィニッシュは7%が3件、10%が6件あり、弱すぎる谷を停止感として感じた可能性がある。13件の短い範囲なので身体感覚や全利用時間を断定しない。最終は本人全停止・2台停止応答OK・error空。
- 完全停止の割合と、動いたまま弱める谷を分離。パターン固有のgap/同%の切れ目/静音処理がそれぞれ停止を増やす構成をやめ、Flickerの予定休止を一つの時間予算で管理する。

## 休止の時間予算

- 段階別のFlicker休止%を初期33/8/1%。本人が各0〜50%を画面で変更・保存できる。出力上限や強度倍率とは別。0%なら予定された完全停止を入れない。一時停止/全停止/異常停止を無効にはしない。
- 一動作を完了した境界で、完了ON秒×p/(100-p)を休み予算へ加える。予算が0.8秒以上なら0.8〜3秒の休みとして消費。余りは持ち越す。33%なら約2秒ON→約1秒休み、8%なら約10〜12秒動いて約1秒休み、1%なら約80〜100秒動いて約1秒休み。各単位が2〜3秒あるため短い観測窓の厳密%ではない。
- 予定休止は配列保持/手動固定/音分類が変わっても別々に加算しない。設定・段階の変更は現在ON完了後に反映し、その段階の予算を新しく始める。停止・上限引下げは即優先。実経過・段階往復・固定パターン/自動は保持。
- 間A/Bの従来表示は維持。導入の休みはA、中間はパターンに応じA/B、フィニッシュはA。F0を作る予定箇所はこの予算だけとし、静音/同値連結/パターン更新で隠れたF0を作らない。

## 動いたままの谷とフィニッシュ配列

- はじめ：7/10%・2秒。中間：既存7/10/15/20%・2〜3秒と40%・1秒の組合せを継承し、配列のgapは7%・2秒の谷へ変換。静音は7/10%・2秒。完全停止だけ時間予算へ集約。
- フィニッシュは専用配列を用意。最小15%・2〜3秒、通常20%・3秒、山40%・2秒を基本に、2→3秒の流れで連続させる。現時点で40%を超える出力へは広げない。40%・2秒は本人の「長めの強い動き」の要望を具体化する初期値で、実機確認済みではない。
- 基準8配列：
  1. 20/3→40/2→20/3→15/2
  2. 40/2→20/3→40/2→15/2
  3. 20/3→40/2→15/2→40/2
  4. 40/2→20/2→40/2→20/3
  5. 15/2→20/3→40/2→20/3
  6. 40/2→20/3→40/2→15/2
  7. 20/3→40/2→20/3→40/2→15/2
  8. 40/2→15/2→40/2→20/3→40/2→20/3
- 同%が隣接する場合は停止を挟まず、別%の谷へ橋渡し。フィニッシュは最低15%、中間は7%。40%が指令上で長く結合しないことを検証。静かなフィニッシュも15/20%・3秒で継続し、時間予算による休みだけ入れる。
- 振動は別トラックを継続。フィニッシュの振動単独REST_B/谷は極弱出力（名目35%の15%=5.25%）を床にして、休み予算外で完全停止しない。Flickerの予定休止Aでは従来通り振動極弱を残す。
