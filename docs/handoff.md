## 実装の入口

- `ScenarioEngine.kt`：振動の8形状・30〜60秒保持・音特徴・時間重み・独立seed。お気に入り由来の強弱範囲と大波を、元の形へ包絡として重ねる。
- `FlickerTrack.kt`：独立抽選と動作単位の%・ON時間。現在ONを完了してパターンを切り替え、休止は段階別の時間予算で決める。音は抽選・次ONへ反映し、実行中の一動作の%・期限は保持。
- `FavoriteCrescendo.kt` / `RestSettings.kt`：お気に入り由来の山谷と時間補間、段階別の休み割合。
- `MotionController.kt` / `CaptureService.kt`：既存の直列actor、取得・接続の所有、選択済み2台の最新値送信と全対象停止。停止待ち中に開始せず、遅い応答・許可で復活させない。
- `MainActivity.kt` / XML / `MotionWaveView`：3画面・生成指令の波形・個別固定と段階往復。見本カードと実行中の選択を区別する。
- `BoilingFrog.kt`とWeb比較fixture：旧19分・以降13分の比較基準。新15分の上限は指令値の天井、旧19分は従来の倍率を保持する。
