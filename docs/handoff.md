- `ScenarioEngine.kt`：振動の8形状・30〜60秒保持・音特徴・時間重み・独立seed。お気に入り由来の強弱範囲と大波を、元の形へ包絡として重ねる。

- `FavoriteCrescendo.kt` / `RestSettings.kt`：お気に入り由来の山谷と時間補間、段階別の休み割合。
- `MotionController.kt` / `CaptureService.kt`：既存の直列actor、取得・接続の所有、選択済み2台の最新値送信と全対象停止。停止待ち中に開始せず、遅い応答・許可で復活させない。
- `MainActivity.kt` / XML：機器タブと下部2画面、個別固定と段階往復。`HandyTrialDialog.kt` / `HandyTrial.kt`：独立した入力テスト・図・共有。削除済みの見本波形画面を復活させない。
