# 振動・Flickerを分けた一動作ベースの生成

更新：2026-10-20 JST。状態：**本人がパターン考案とシナリオへの実装を依頼、0.6.0実装・自動検証済み、端末更新済み、実機の使用感確認待ち。具体配列は調整可能な初期値**。本人は「40%・1秒を少し挟み、その後15%・2秒でも全体では弱い刺激」「弱めの区間と動く区間の調整」を説明し、振動とFlickerを別動作としてシナリオ化するよう依頼した。[単発での本人評価](flicker-trial.md#本人による動作単位の評価と強弱の捉え方)を根拠にする。

## 境界

- 新しい15分・エンドレスだけを改修。比較用19分と単発確認は保持。アプリID・署名・接続・対象2台・全停止を継続利用。
- 振動：0.4の滑らかな包絡・形・状態を基準に、従来の上限35%時の指令を名目出力へ変換し、感触の基準を保つ。
- Flicker：波形の微小値へ追従させず、「実指令%・ON時間・次の間」を持つ動作単位を並べる。音量を重ね掛けして7%を薄めない。
- 両系統の上限は、新方式では生成値へ掛ける倍率ではなく実指令の天井として適用する。保存設定は変えず、両方100%という本人の案を勝手に既定値へしない。通常Flickerは7%を最弱候補として使うため、それ未満の上限では開始前に調整を案内する。
- 同じフレーム内に独立した振動・Flickerを合成し、機器別に量子化。第3系統なし。追加機器を自動で加えない。

## Flickerの8パターン（初期配列）

`7/2`は7%・2秒。単発で良好だった7/2、本人が提示した10/3・15/2・20/2・40/1を軸にする。試していない組合せも初期案であり、快適さを確認済みとは扱わない。

| パターン | 一動作の並びの基準 |
| --- | --- |
| ゆっくり往復 | 7/2 → 間A → 10/3 → 7/2 |
| 触れて、間を置く | 10/2 → 間A → 7/2 → 間B |
| まばらな小波 | 7/2 → 長めの間A → 15/2 → 7/2 |
| ずらした二連 | 15/2 → 短めの間A → 10/3 → 7/2 → 間A |
| 階段と戻り | 7/2 → 10/3 → 15/2 → 20/2 → 7/2 |
| 短い山と余韻 | 40/1 → 15/2 → 7/2 → 間A |
| ほどける波 | 15/3 → 10/2 → 7/2 → 間A → 20/2 |
| 変わるまとまり | 20/2 → 7/2 → 40/1 → 10/3 → 間B |

- 同じ%の一動作が続く場合は短い間A（0.8〜1.2秒）を挟み、40%・1秒などが指令上で連結して長くならないようにする。
- 間A：Flicker0、振動は極弱を残す。間B：両方0の予定休止。Flickerの一動作を終えてから入れる。長さは一か所の設定に集約し、100ms未満を作らない。
- 振動とFlickerのパターン抽選・乱数・内部の時計を分ける。通常の種類の保持は各30〜60秒を基準とし、Flickerは期限が来ても動作中の一動作を終えてから次へ（最大1単位分延長）。音が変わるたび保持期限をリセットしない。同一3連続は避ける。
- 形を知る見本と実行を分ける。見本カードを押しても実機へ送信・実行中レシピの上書きをしない。

## 段階・音・停止

- はじめは7/2〜15/2など2〜3秒の弱い単位中心。中間弱めは20/2まで、中間強めは40/1も混ぜる。フィニッシュは20/2・40/1を増やし、15/2へ戻す。初期の通常最大は40%・1秒で、上限100%だから100%を自動採用するわけではない。
- 選択するスタイルの配分は既存の15〜45分の混合を継承する。スタイル選択の割合と、実際のFlickerの強い指令時間の割合を混同しない。振動の強め時間の既存検証もFlickerの時間比率と読み替えない。
- 音は次の一動作の候補・間の長さ・パターン抽選へ反映。実行中の一動作の%や期限は瞬間的な音で変えない。静かになったら現在の単位を完了し、次を7/2＋長めの間へ寄せる。振動は既存の包絡で弱める。無音でも時計は進み、予定されたFlickerの間は新仕様で許容する。
- 明示スキップは進行位置を変え、Flickerの現在の一動作が終わったところで新しい段階へ。振動は平滑化を保って移行。無操作は自動進行。
- 一時停止・全停止・異常停止は一動作より優先する。一時停止で中断した単位は、明示再開時に同じ条件の一回分をやり直す。段階・パターンID・実経過は保持する。
- 出力上限を本人が下げたときはその上限を直ちに優先。一動作完了のために上限を超えない。接続だけ・復帰だけで開始しない。

## 中間・強めの初期設定

本人の追加依頼は「中間区間と強め区間をある程度の完成品として実装し、実機を見て感想で改善」。このためパターン設計を単なる保留案で終えず、以下を調整可能な初期設定として使用する。

| スタイル | 基準配列の変換 |
| --- | --- |
| 導入 | 20%・2秒→10%・3秒、40%・1秒→15%・2秒。他は保持 |
| 中間弱め | 40%・1秒→20%・2秒。他は保持 |
| 中間強め | 基準配列。40%・1秒→15%・2秒の落差も保持 |
| 強め | 7%・2秒→15%・2秒、10%→20%・2秒、15%→15%・2秒、20/40%→40%・1秒 |

「強め」でも15%・2秒へ戻し、40%の連続ではなく長短と戻りで差を作る。5〜12分は中間弱め/中間強めの割合を段階的に変え、12〜15分から強めを混ぜる。15分時点は中間弱め10%・中間強め40%・強め50%、45分以降は5/20/75%の選択比率。動作%や実時間比率とは別。

音密度が高いと間を短い側へ、低いと長い側へ寄せる。静音時は現在ONを終えて7%・2秒と長めの間Aを交互にする。音が戻れば静音判定を即座に外し、次の単位から通常配列へ戻る。
