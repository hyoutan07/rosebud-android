## 今できること

セッション画面の吸引の下に「Handy · 無送信プレビュー」を追加。明示開始し、別時計で進行する。既存V/Fの開始ボタンとは別。実機モードでV/Fが動いていてもHandyのプレビューは無送信。音追従ONは既存の取得を必要とし、同じAudioFeaturesを参照する。OFFは曖昧な音の特徴で生成し、疑似音声を取得済みとは表示しない。

- 初期8分→7分→フィニッシュ5分の展開を反復。20分で終了せず、5分ごとに配列を先頭へ戻さない。開始前に各段階1〜60分へ変更できる。
- 専用の3候補「幅の波」「二連と余韻」「反復と間」。全段階で時間・幅・間の係数を変える最小版。20秒以上保持した後、音の分類が変わるか80秒を超えた次の区間境界で抽選する。80秒で途中の動きを切らない。
- 相対重み10〜200を候補ごとに設定。音の分類の重み×個人重み×直前候補の抑制で抽選。名前・係数・音との対応は**仮**、出現率の保証や本人の好みの確定ではない。
- 「Handyだけ弱める」でHandyの進行時計・保持年齢を保留。区間境界で弱い動きへ移る。解除は手動、次の境界から仮3秒の復帰係数を使う。V/F・吸引の時計と生成には作用しない。
- 手動フィニッシュ移動はフィニッシュの第1展開へ。移動中の区間は急に置き換えず、弱化中は移動できない。
- Handyプレビュー終了はHandyだけ。全停止・通知停止・障害停止・V/Fの一時停止はHandyプレビューも終了。V/Fの再開だけでHandyを再開しない。
- 設定は折りたたみ。Handy用のキーのみ保存し、既存の上限・休み割合・追従・接続先を変更しない。保存復元では開始せず、対象選択も復元しない。

生成目標、片道の生成時間、段階・保持時間・予定された間を表示。**現在位置は未取得、目標到達は未確認**と表示する。接続機器の停止応答とプレビュー終了を混同しない。無音の特別な弱化仕様は未合意のため、今回QUIETは通常の抽選の既定重みを使用する。

## 位置・送信準備

`ControlDevice`で従来の厳密なScalar0 Vibrate / Scalar1 Rotate+Flicker判定を保持し、別に単一Linear/Position、正のStepCount、Handy名の位置専用機器を識別する。名前は診断用の保守的な対象絞り込みで、機種・FW・停止能力の認証には使わない。Scalar定義を持つ混合機器や未知の位置機器は今回対象外。v3定義の実機取得は未実施。

明示選択と全台選択は位置機器を含められるが、新規検出は選択へ追加しない。**位置機器が含まれる実機V/F開始は理由を表示して拒否**する。現行版で実機V/Fを使う場合は「Rosebud対象すべて」で既存2台だけをまとめて選べる。3台を選択した際の全停止は全対象にStopDeviceCmdを要求するが、HandyのOkは必ず「停止未確認」にする。機器消失後も選択時の位置機器判定を保持する。

`LinearMove.body`はv3 LinearCmdの単一Vectorsを生成する（Position=0〜1、Duration=ms、DeviceIndexとfeature Indexは別）。`LinearLane`は**後続接続用の準備部品**で、本番Controllerの送信ループにはまだ接続していない。これを実機送信まで完成したと扱わない。

- 機器ごとに1件の応答待ちと別の移動期限。両方を満たしてから次の区間へ。Okは位置や到達の情報ではない。
- 1500ms超の応答待ちで世代を更新して無効化。再び明示的にarmするまで送らない。停止・再接続で旧応答は復活しない。
- gap、移動時間2〜20秒、目標10〜90%、正規化速度0.1/秒以下を検査。既知の開始位置でarmが必要。時刻が遅れても古い位置列をキューに積まない。
- プレビューの初期範囲45〜55%、基準片道3秒。UIの下限40〜48%、上限52〜60%、基準片道2〜10秒に限定し、段階・候補によって生成時間を延ばす。距離に応じて0.05/秒以下に抑える。これらは制限付きの仮指令値で、mm、実速度、物理最小値、推奨設定ではない。

初期位置を勝手に中央へ動かす処理はない。Handyの現在位置の入力・取得・初期合わせUIは未接続で、通常出力を解除する際に改めて必要。既存PRNGを呼ばず、seedを分離。V/FのScenarioEngine/FlickerTrack/BoilingFrog/SuctionTrackは変更していない。
